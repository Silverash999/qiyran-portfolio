RATE STRATEGY｜费率策略

平台费率策略

参与季度品牌等级调整，评估收费变化、影响范围和商家流失风险。

  • 使用 SQL 测算品牌分层后的收费变化和受影响商家数量。
  • 品牌等级以季度数据为基础，结合品牌 GMV、出价商品数、高价率等指标计算等级区间；国家补贴调整、同质化商品、打版抄袭和知识产权等情况也会影响等级判断。
  • 使用 SQL 获取品牌维度的订单、GMV 和收费金额，测算等级变动前后的预计收费变化、受影响商家数量，并结合现有激励和优惠政策提出调整建议。
  • 类目运营提出，部分品牌的问题来自非主营类目，直接按品牌整体降级会扩大影响范围。针对这一情况，收集需要维持的品牌 × 类目清单，重新测算细化维度下的影响金额。
  • 当时内部收费配置尚未支持类目维度，提交相关产品需求，并与行业、财务、商管共同确定影响额阈值和最终调整名单。
  • 调整完成后，以商家是否仍有出价和动销判断流失情况，并持续监控品牌 GMV 和收费金额。
  • 日常监控中曾发现某商家品牌收费率异常。排查数据源、历史数据、商家规则和品牌/类目订单后，确认原因是类目切换和商品迁移未被配置规则覆盖。随后上报、人工修正配置，并在订单状态沉淀后核算收费差异和返款。

项目结果

<1%

涉及 1300+ 品牌
日均 GMV 保持 180 万+
单均收费上涨约 2%
